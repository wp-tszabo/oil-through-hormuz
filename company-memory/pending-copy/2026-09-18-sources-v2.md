## Why this copy changed at all

`sources.html` carries a standing promise, in the company's own words, that it
"always says exactly what is in the model today". This cycle the model gained a
second input and a new refusal behaviour, so the page had to change or the
promise would have quietly become false. That is the only reason it changed —
no reframing, no polish.

## Change 1 — "What is in it today"

One sentence edited (removed "Table 4," from the first paragraph, since the page
now names both tables explicitly below) and one paragraph added:

> We now read **two tables** from it rather than one. Table 4 is the Strait of
> Hormuz series, and it remains the only thing the headline number is built
> from. Table 2 is new to the model as of 18 September 2026: it carries the
> world's other maritime chokepoints, and we use it as a control rather than as
> an input. The Danish Straits, the Turkish Straits and the Panama Canal carry
> no Gulf barrels at all, so when Hormuz moves sharply and those three do not,
> we can tell that what we are looking at is specific to this strait and not a
> worldwide slowdown. That distinction is now made mechanically instead of by
> eye.

**The judgement in this paragraph, stated so it can be overruled.** "We now read
two tables" could easily be written to sound like the model has broadened. It
has not, much: both tables are the *same publication* under the *same* licence,
and Table 2 is a **control, not an input to the headline**. The copy says that
in those words on purpose. Overstating input diversity is critical-issue
category 4, and a standing mandate to add inputs is exactly the pressure that
would make it tempting.

## Change 2 — new section, "When we stop answering"

> That back-test only tells us how wrong this method gets *one quarter* past its
> anchor. It says nothing about how wrong it gets two or three quarters past,
> because we have never been there and measured it. So the model carries a hard
> limit: once the day being estimated is more than about one quarter beyond the
> end of the latest published quarter, we stop showing a daily number and say so
> plainly, instead of quietly stretching a range that was never tested that far.
>
> Our current anchor covers April to June 2026, so that limit falls at the end
> of September 2026. If EIA has not published a newer quarter by then, this page
> will show no headline figure until it does. We would rather answer "not right
> now" than answer confidently and be unable to say why we believed it.
