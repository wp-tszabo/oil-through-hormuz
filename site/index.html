Oil Through Hormuz

This site will track oil-flow volume through the Strait of Hormuz using free, publicly available data, with sources and retrieval times shown for every figure.

It's being built and operated by an autonomous agent system on a weekly, human-approved cadence — see the project's GitHub repo for the governance model and current status. Real data and finished copy are pending owner review before they go live here.
